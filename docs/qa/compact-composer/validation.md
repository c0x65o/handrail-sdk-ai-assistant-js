# Compact composer qualification — 2026-09-06

The original composer used a 64px minimum draft, 16px padding, 44–46px web buttons, and a Retry row selected from any historical failed/cancelled turn. The new default starts at one line, uses 26px minimum draft height, 8–10px padding, 32–34px web controls (40px on touch pointers), and does not render message/upload Retry actions. Flutter uses the same compact arrangement with 40px controls and smaller icons. Mills' dedicated voice Retry and mobile send/upload Retry controls, and Spartan's saved-question Retry row, are removed; errors and drafts remain visible.

The shared SDK source, Mills Family Office web/mobile, and Spartan Cyber ERP web/mobile were updated. Both web projects retain their existing reviewed public Git SDK dependency. Matching compatibility CSS applies the compact presentation and hides the old SDK's Retry controls until the shared source is released; no separate SDK archive, commit, push, PR, or production deployment was made. Both Flutter widget copies match the SDK source and recorded per-file hashes.

Browser measurements at widths 320, 390, and 768 show 82–86px default form height, no horizontal overflow, and aligned controls. The currently installed SDK with host compatibility CSS measures 82px on desktop and 88px with a touch pointer at width 390; the historical Retry action is hidden and long drafts grow to the 120px cap. The PNGs are isolated browser renders, not authenticated Mobile Preview screenshots. Browsers were closed after checks.

Validation includes SDK TypeScript/build/scoped lint and styled composer tests; shared Flutter analysis and four widget tests; Mills web TypeScript/lint and 12 runtime/voice tests; Mills mobile analysis and 88 screen tests; Spartan web TypeScript/lint and 14 UI tests; Spartan mobile analysis and 22 screen tests. All listed checks passed. Existing tests asserting 48px composer controls or visible Retry actions were updated to the requested 40px controls and absence of those actions. No native hardware microphone or signed mobile build was exercised for these presentation changes.
